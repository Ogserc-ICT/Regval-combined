# Acceptance checks: where each one is proved

The brief's acceptance checks (`docs/COMBINED_BUILD.md`) and the automated test that proves each one. Unit tests run with `pnpm test:unit`; integration tests run against a real PostgreSQL with `pnpm test:integration`. All pass as of Phase 9 (10 Nov 2026). The registry checks (shared ACK series with the Registry, routing, unit emails) were removed with the Registry.
